# Notice

## Support

Databricks does not offer official support for this demo application and its repository.

For any issues with these assets or the demo installation, please open an issue using
GitHub and the team will review on a best-effort basis.

## Demo-Only Notice

This application is built for **demonstration purposes only**. It should run in an
isolated Databricks workspace and should not be connected to:

- Production Unity Catalog data
- Production SQL warehouses
- Live customer systems or real PII

The demo uses **synthetic / sample energy consumption data** only.
